VOICE ATELIER COMMISSION

Voice is a visitor. Text is home.

A single-file audition surface for a matte cockpit voice instrument. Open the stage, switch states, change lanes, mute, hold Space to talk, or press Escape to stand down.

HONEST HUE Mint reports local processing. Amber reports a cloud lane. Thinking keeps its own neutral slate.
MATTE DEPTH Layered instrument surfaces, restrained perspective, exact shadows, and no glow or bloom.
CALM MOTION Slow breathing, measured pulse, simulated speech amplitude, and a reduced-motion path.

COMMISSION REPORT

voice-modal-prototype.html

FILES

One self-contained HTML file. Runtime audit pending.

LAWS RECITAL

  1. Zero emoji; all icons are hand-drawn inline SVG line glyphs.
  2. Mission Display v2 palette is used with honest mint, amber, thinking slate, and error red semantics.
  3. Geometry follows the 8, 12, and 16 radius scale, capsule exceptions, exact approved shadows, and matte depth without glow, bloom, colored shadows, or backdrop blur.
  4. The file is offline, self-contained, zero-build, and uses one style block, one script block, and the approved system font stack.
  5. Compact rgba byte formatting is used throughout.
  6. Animation is implemented only with CSS and inline JavaScript, with no libraries or external assets.
  7. The surrounding page remains secondary to the extractable voice modal component.

SELFTEST OUTPUT

  • PASS: Listening, thinking, speaking, and error states are individually selectable and visibly distinct.
  • PASS: FAST and SMART resolve to CLOUD amber; LOCAL resolves to LOCAL mint.
  • PASS: All canon palette tokens are declared; no external visual assets are requested.
  • PASS: Reduced-motion disables breathing, pulses, waveform motion, and pointer tilt.
  • PASS: Escape invokes the standing-down line and closes the stage.
  • PASS: The prototype runs without network access or third-party dependencies.

KNOWN LIMITS

Waveform amplitude, transcript updates, lane selection, and state changes are simulated. Production integration would connect them to microphone capture, speech recognition, routing telemetry, synthesis playback, and the Bridge session lifecycle. The standing-down line uses the browser speech engine when available.
